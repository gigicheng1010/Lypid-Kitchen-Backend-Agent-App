# 粉絲數顯示與歷史變動規則

## 顯示格式

- 小於 10,000：顯示精確整數，例如 `882` 或 `9,229`。
- 10,000 至小於 1,000,000：使用千位單位，例如 `10K` 或 `36.4K`。
- 1,000,000 或以上：顯示可讀的百萬單位，例如 `1.2M`。

## 增減箭頭

- 每日快照逐一查詢 Instagram 公開個人頁；成功數值快取 24 小時，查詢失敗時每小時重試並暫用工作表數值。TikTok 使用工作表快照。
- 箭頭只比較同平台、同創作者、同資料來源的最近兩筆每日快照；來源不同或沒有前一筆資料時不顯示。
- 上升：綠色向上箭頭，例如 `▲ +1,240`。
- 下降：紅色向下箭頭，例如 `▼ −860`。
- 無歷史資料、來源變更或數值相同：不顯示箭頭。

## 資料來源優先順序

1. Meta Business Discovery API 精確值。
2. Instagram 公開個人頁精確值。
3. 試算表粉絲快照；未驗證時標示為非即時資料。

Instagram 公開頁未提供可解析數值時會沿用試算表記錄並在清單中標示為非即時資料。TikTok 目前只顯示試算表數值。
