# 粉絲數顯示與歷史變動規則

## 顯示格式

- 小於 10,000：顯示精確整數，例如 `9,229`。
- 10,000 至小於 1,000,000：顯示可讀的千位單位，例如 `36.4K`。
- 1,000,000 或以上：顯示可讀的百萬單位，例如 `1.2M`。

## 增減箭頭

- 每日快照使用同一平台、同一創作者姓名比對最近兩筆資料。
- 上升：綠色向上箭頭，例如 `▲ +1,240`。
- 下降：紅色向下箭頭，例如 `▼ −860`。
- 無歷史資料、來源變更或數值相同：不顯示箭頭或顯示 `—`。

## 資料來源優先順序

1. Meta / Instagram 公開頁面當天精確值。
2. 試算表粉絲快照。
3. 未驗證時不標示為即時資料。

TikTok 目前沒有可放入公開頁快照的可靠資料來源，因此只顯示試算表數值。
